# Repository documentation records

This directory keeps the durable records that repository gates and offline
checkouts need:

- `adr/` contains architecture decision records.
- `dependency_forks.md` is the normative maintained-fork policy referenced by
  `AGENTS.md`, `CONTRIBUTE.md`, `scripts/check_libxev_fork.sh`, and the
  build/vendor agents.

Narrative guides, protocol descriptions, deployment instructions, and
operational runbooks live in the GitHub wiki:
https://github.com/farbenbuilds/uWebZockets/wiki

Benchmark result READMEs and manifests stay under `benchmarks/results/`. Raw
benchmark evidence archives are intentionally not committed.
