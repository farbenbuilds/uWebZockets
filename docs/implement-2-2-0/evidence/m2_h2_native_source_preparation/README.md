# Exact native source preparation evidence

This checkpoint prepares and verifies source inputs for combined HTTP/2 native
testing. It performs no target compilation or execution, changes no production
pin and does not complete M2.

- [Focused report](../../m2_h2_native_source_preparation.md)
- [Archive](native-source-preparation.tar.gz)
- [Manifest](manifest.json)

`packet/` embeds 800 retained evidence files, including current helpers, exact
origin ledgers, actual source inventories, commands/results, failed versions,
original reports/seals and both preservation corrections. Nine large identical
Git batch outputs remain intact locally and are represented by their exact
immutable-object reproduction contract. `evidence/` retains the full report,
all three independent verdicts verbatim, scoped diffs and Root audit sources
and results. `reconstruction/supplements/` contains the nine exact historical
supplemental source files needed alongside the base Git objects and archived
40-file delta.

The current preparation helper still reads the original absolute snapshot
paths. Consuming these archived supplements on another checkout requires an
adapted, reviewed recipe; no portable reconstruction command is claimed.

`INVENTORY.json` binds every other archive member's size and SHA256. All members
are regular and nonexecutable. Sixteen small binary Git object/tree records
have an explicit hash-bound allowlist and originating command receipts; all
other members are UTF-8. They are provenance data, not newly built targets.

The accepted fresh preparation verifies 1,031 candidate and 93 libxev files,
exact directory sets and immutable modes. Actual protected directory lists
were captured before the fresh run and compared afterward. The first run's
missing empty-directory history remains unproved; its original evidence is
preserved. Final scoped review resolves both findings. Initial context-only
logging and all remaining native/runtime/project/platform/adoption limits are
explicit in the reports.
