# Native fixture-capture source evidence

This archive preserves the reviewed pure post-facts helper, focused tests and
privacy preparation. The [manifest](manifest.json) binds the archive and
declares every environment substitution. `INVENTORY.json` inside the archive
binds every public regular, non-executable UTF-8 member by size and SHA-256.

- `native/` contains the five current native helper/test modules and complete
  evidence path set, with the 25 declared environment substitutions.
- `reference/` contains the accepted combined/canonical source references.
- `evidence/` contains briefs, reports, the original parser finding, approved
  fix, full privacy verdict, review packages and Root verification controls.

Private original environments are excluded. Their safe replacements retain
only the actual source-controlled Python settings; nine early records omit
the seed that was not recorded. Public environment bytes deliberately differ
from the full originals. Synthetic leakage-test environments contain fake
sentinels only and remain evidence of that failure. All other bytes are retained.

The current wrapper captures only its three explicit settings. Archived scripts
are non-executable data; invoke the current wrapper with `bash` after restoring
its recorded source inputs. Commands retain original absolute paths. The
archive does not claim a portable native runner or a complete interpreter,
loader and SSL closure.

The source proofs cover strict 75-marker captures, canonical comparisons,
1,485 field mutations, 380 diagnostic placements, bounds and import inertness.
Actual PID/listener/signal/deinit/exit/reap/cleanup proof, fresh builds, native
all40 and final project/platform acceptance remain open. See the
[checkpoint report](../../m2_h2_native_post.md).
