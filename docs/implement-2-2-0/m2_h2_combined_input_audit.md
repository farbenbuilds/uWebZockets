## Native mismatches and remaining work

The historical runtime cannot be installed wholesale. It returns five
connection outputs where the coordinator requires seven, rejects EOF in its
ordinary read helper, uses seconds-based shutdown budgets, validates 32 records
instead of 67, and duplicates termination ownership. Native helpers must keep
the canonical coordinator and single termination owner, use integer caller
deadlines, and compare actual producer/binding/file facts.

The source run's binding generation 18 and RX/read/refund counts describe that
execution. Native scheduling must preserve semantic contracts and original
ceilings while recording its own observations.

The active EOF contract remains unresolved in this checkpoint. An
`SSLEOFError` does not disclose an internally consumed prefix or establish
complete wire truth. Ordinary observer poisoning stays intact; no exception
policy or closing-window extension is approved here. Immutable pre-signal
facts and separately observed closing traffic need a reviewed contract before
native implementation.
